# Terminal Retro

Uma aplicação React que simula um terminal antigo com visual retrô, inspirado em terminais clássicos.

## Características

- Visual retrô com tela verde escura e texto verde fluorescente
- Cursor piscante animado
- Efeitos de brilho e sombras
- Comandos funcionais básicos
- Navegação pelo histórico de comandos (setas para cima/baixo)

## Instalação

```bash
npm install
```

## Executar

```bash
npm run dev
```

## Comandos Disponíveis

- `help` - Mostra os comandos disponíveis
- `clear` - Limpa o terminal
- `date` - Mostra a data e hora atual
- `whoami` - Mostra informações do usuário
- `echo [texto]` - Repete o texto digitado
- `ls` - Lista arquivos (simulado)
- `pwd` - Mostra o diretório atual
- `exit` - Fecha o terminal

## Tecnologias

- React 18
- Vite
- CSS3 (animações e efeitos visuais)
